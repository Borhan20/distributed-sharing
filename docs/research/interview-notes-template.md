# Interview notes (plan §13)

Use one copy per interview. **No personal data:** record a participant code
(P1, P2, ...) and a role, never a name, e-mail address or machine hostname.

| | |
|---|---|
| Participant | P_ |
| Role | e.g. researcher, student, developer |
| Date | |
| Interviewer | initials |

## Questions

1. The last time you waited on compute, what were you running, and how long did you wait?
2. What did you do instead: cloud, a smaller model, an overnight run, or gave up?
3. What hardware do you have, and when is it usually idle? (Also fill in `hardware-inventory-template.csv`.)
4. Would you let a teammate's job run on your machine? Under what conditions?

## Classification

Pick one, based on the answers (plan §13 "How to read the answers"):

- [ ] Mostly "borrow a machine" → Phase 1 is the product
- [ ] Mostly "too many runs" → move Phase 2 forward
- [ ] Mostly "one huge run" → Phase 4 moves up
